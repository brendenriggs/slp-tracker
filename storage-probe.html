What this test is actually doing

It writes a small note with a random code into the browser's built-in storage (IndexedDB, plus localStorage as a cross-check), then looks for that same code after you reopen the file. If the code comes back, storage works and survives a restart. It also tries the newer "save directly to a file" feature and checks whether the connection to that file can be restored later without picking it again. No data leaves the computer and nothing is installed.
